# AGENTS.md (docs/tasks)

- Claim a task by moving its line to **In progress** with your name before you start, and commit that change first so others see it.
- Tick acceptance criteria in the task file as you meet them. Do not tick a criterion you did not verify.
- If a task is bigger than its estimate, stop and split it into new task files instead of growing the PR.
- Questions go at the bottom of the task file, with the reading you chose.
