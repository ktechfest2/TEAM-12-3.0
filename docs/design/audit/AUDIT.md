- API: started and healthy, but the memory backend has no seeded claims or messages. `make demo-reset` was not run (needs sql backend and Postgres, not available here).
- Dashboard data is MOCKED (Playwright `page.route`, invented demonstration data). The reviewer session token in sessionStorage is invented.
- Real reviewer login was NOT attempted: no local dev invite code was available and none was searched for.
- Contrast: computed from the computed foreground and the composited ancestor background; default base is white where no opaque ancestor exists. Opacity multiplied in. Text with an image background would be flagged (none found).
- Targets: `a[href], button, input, select, textarea, summary, [role=button|link|tab|checkbox|radio]` under 40px in either dimension. Visually hidden 1px elements excluded.
